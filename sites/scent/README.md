# scent.reason.place

Static fragrance collection overview for `https://scent.reason.place/`.

## Cloudflare Pages

Create a Pages project from the `ReasonJ01/reason.place` repository using:

- Production branch: `main`
- Framework preset: None
- Build command: leave blank
- Build output directory: `sites/scent`

After the first deployment succeeds, add `scent.reason.place` as the custom domain.

The site is intentionally a compact overview: fragrance name, creator, notes, creator/house intention where available, and an external reference link.
